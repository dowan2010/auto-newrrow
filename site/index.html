AI가 대신 써요.

뉴로우에 로그인해서 계획을 정리하고 회고를 작성·제출하는 일을 버튼 한 번, 혹은 매일 자동으로 해 줘요.

Mac용 다운로드 Windows용 다운로드

Mac은 Apple Silicon(M1~M4), Windows는 64비트예요.

오늘의 계획과 회고

AI가 대신 작성해서 뉴로우에 제출해요.

매일 같은 입력을 반복하지 않아도 돼요.

1

계획과 회고를 한 번에

할 일을 불러와 계획을 정리하고, 그날 주제를 정해 회고를 써서 제출까지 이어서 해요.

2

매일 자동 실행

앱을 열어 두지 않아도 정해진 시간에 실행돼요. 일시적인 오류에 대비해 하루 3번 시도하고, 이미 끝난 날은 건너뛰어요.

3

AI는 고르는 대로

Gemini, GPT, Claude 중에서 선택해요. Claude는 내 구독 사용량을 쓰는 토큰도 쓸 수 있어요.

4

내 컴퓨터에만 저장

비밀번호와 키는 이 컴퓨터에만 저장돼요. Mac은 권한 600 파일, Windows는 자격 증명 보호로 암호화해요.

5

실행 기록

자동으로 돈 결과와 로그를 앱에서 바로 볼 수 있어요. 실패하면 원인(예: 아이디/비밀번호 오류)이 화면에 떠요.

6

알아서 업데이트

새 버전이 나오면 알림이 뜨고, 버튼 한 번으로 받아서 교체해요. 무엇이 바뀌는지도 같이 보여줘요.

세 단계면 돼요.

설치

내 컴퓨터에 맞는 파일을 받아 설치해요. 서명되지 않은 앱이라 처음 한 번만 아래 설정 안내를 따라야 해요.

정보 입력

뉴로우 이메일과 비밀번호, 쓸 AI 서비스와 키를 넣고 저장해요.

실행

지금 실행을 누르거나 매일 자동 실행을 켜요. 그다음부터는 알아서 돌아가요.

설치와 설정.

Mac

1. .dmg를 열어 앱을 Applications로 끌어다 놓고, dmg는 꺼낸 뒤 앱을 실행해요.

2. "손상되었기 때문에 열 수 없습니다"가 뜨면 서명 안 된 앱이라 Mac이 막는 거예요. 터미널에서 한 번만 실행하세요.

xattr -dr com.apple.quarantine "/Applications/Auto Newrrow.app"

Windows

설치 파일을 실행하면 바로 설치돼요. SmartScreen이 막으면 추가 정보 → 실행을 누르세요. 자동 실행은 PC가 켜져 있고 로그인된 상태여야 해요.

AI 키는 어디서 받나요

Gemini API 키
  1. aistudio.google.com/apikey에서 구글 계정으로 로그인해요.
  2. Create API key로 키를 만들어 복사해요.
  3. 앱의 AI 서비스를 Gemini로 두고 붙여넣어 저장해요.

무료 사용 한도가 있을 수 있어요. 한도와 정책은 Google 안내를 따라요.

GPT(OpenAI) API 키
  1. platform.openai.com/api-keys에서 로그인해요.
  2. Create new secret key로 키를 만들어 복사해요.
  3. 앱에서 AI 서비스를 GPT로 바꾸고 붙여넣어 저장해요.

사용량에 따라 요금이 나가요. 회고 하나는 아주 적은 양이라 보통 비용이 매우 작아요.

Claude 토큰 (구독 사용량)
  1. 컴퓨터에 Claude Code를 설치하고 로그인해요.
  2. 터미널(Mac은 터미널 앱, Windows는 PowerShell)에서 아래 명령을 실행해요. 브라우저에서 로그인하면 sk-ant-oat…로 시작하는 토큰이 나와요.
claude setup-token
  1. 앱에서 AI 서비스를 Claude로 바꾸고 토큰을 붙여넣어 저장해요.

내 클로드 구독의 세션 사용량을 써요. 일반 Anthropic API 키(sk-ant-api…)도 같은 칸에 넣을 수 있어요.

불러오는 중…

자주 묻는 질문.

안전한가요? 내 비밀번호는 어디로 가나요?
비밀번호와 API 키는 내 컴퓨터에만 저장돼요. 뉴로우에 로그인할 때와 선택한 AI 서비스를 호출할 때를 빼면 어디로도 전송되지 않아요.
꼭 컴퓨터가 켜져 있어야 하나요?
네. 자동 실행은 정해진 시간에 컴퓨터가 켜져 있어야 해요(Windows는 로그인된 상태). 잠자기였다면 깨어난 뒤에 실행되고, 네트워크가 연결될 때까지 기다려요.
자동 실행은 언제 도나요?
설정한 기준 시간부터 4시간 뒤, 12시간 뒤까지 하루 3번 시도해요(08:30이면 08:30 / 12:30 / 20:30). 이미 완료된 날은 건너뛰어서 중복 제출되지 않아요.
"아이디 또는 비밀번호가 틀려요"가 떠요.
설정의 이메일과 비밀번호를 다시 확인하세요. 뉴로우 서버가 로그인을 거절했다는 뜻이에요.
업데이트는 어떻게 하나요?
새 버전이 있으면 앱 위쪽에 알림이 떠요. 업데이트를 누르면 받아서 교체하고 다시 켜져요. 이미 등록한 자동 실행은 그대로 유지돼요.
누가 만들었나요?
개인이 만든 비공식 도구예요. 뉴로우와는 관계가 없고, 본인 계정에만 사용해 주세요.

지금 받아 보세요.

무료예요. 설치하고 정보만 넣으면 끝이에요.
