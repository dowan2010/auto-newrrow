자동 실행

매일 자동 실행은 어떻게 동작하나요

매일 자동 실행을 켜고 시간을 정하면 그 시간에 앱이 알아서 계획과 회고를 작성해요. 일시 오류에 대비해 4시간 뒤, 12시간 뒤에도 한 번씩 더 시도하고, 이미 완료된 날은 건너뛰어요. 앱을 열어 둘 필요는 없고, 끝나면 알림이 떠요.

  • 컴퓨터가 그 시간에 켜져 있어야 해요 (Windows는 로그인된 상태).
  • 잠자기 상태였다면 깨어난 뒤에 실행돼요.
  • 이미 완료된 날은 건너뛰어서 중복으로 제출되지 않아요.
실행 중에 창이 보였으면 좋겠어요 / 보이지 않았으면 좋겠어요

매일 자동 실행 카드의 실행 중 로그인 창에서 숨김/보기를 바꿀 수 있어요. 기본은 숨김이고, 문제가 생겼을 때 켜서 확인하면 좋아요.

문제 해결

계획이나 회고가 가끔 안 돼요

뉴로우 서버가 잠시 불안정하거나 네트워크가 끊기면 한 번씩 실패할 수 있어요. 앱에서 지금 실행을 다시 누르면 이미 끝난 부분은 건너뛰고 남은 부분만 이어서 해요.

계속 실패하면 실행 중 로그인 창을 켜고 다시 실행해 보세요. 진행 상황 영역에 어느 단계에서 멈췄는지 표시돼요.

"설정이 비어 있어요"라고 나와요

이메일, 비밀번호, 선택한 AI 서비스의 API 키 중 하나가 비어 있다는 뜻이에요. 계정 카드를 채우고 저장해 주세요. AI 서비스를 GPT로 바꿨다면 OpenAI 키도 따로 넣어야 해요.

로그인 실패라고 나와요

이메일·비밀번호가 맞는지 확인하고 다시 저장해 보세요. 뉴로우 사이트에서 직접 로그인되는지도 확인해 보세요. 앱을 처음 켠 직후에는 한 번 실패할 수 있어서, 다시 눌러 보면 돼요.

Mac 비밀번호를 자꾸 물어봐요 (키체인 팝업)

1.3.5부터는 키체인을 쓰지 않아서 이 팝업이 더 이상 뜨지 않아요. 이전 버전에서 업데이트한 뒤 처음 한 번만 예전에 저장한 값을 옮기느라 물어볼 수 있어요. 이때 Mac 로그인 비밀번호를 넣고 허용을 눌러 주세요. 그 뒤로는 묻지 않아요.

이 한 번을 자동 실행 시간에 만나면 아무도 못 봐서 멈출 수 있어요. 업데이트한 뒤에 앱을 한 번 직접 열어 두세요.

회고를 초기화했는데 다시 못 써요

뉴로우에서 그날의 회고를 초기화하면 같은 날에는 에이전트 방식으로 다시 쓸 수 없어요. 다음 날부터 정상으로 돌아와요.

정보와 안전

내 정보는 어디에 저장되나요

비밀번호와 API 키는 이 컴퓨터에만 저장돼요. macOS에서는 내 계정만 읽을 수 있는 파일(권한 600)에, Windows에서는 자격 증명 보호(DPAPI)로 암호화해서 저장해요. 서버로 보내지 않고, 로그인할 때 뉴로우와 글을 만들 때 선택한 AI 서비스(Google 또는 OpenAI)에만 쓰여요.

쓰기 전에 알아둘 점
  • 비공식 도구예요. 뉴로우 화면이나 방식이 바뀌면 동작이 깨질 수 있어요.
  • 본인 계정에만 사용해 주세요. 자동으로 만든 회고도 본인 이름으로 제출돼요.
  • 학교나 기관의 이용 규정을 확인하고 사용해 주세요. 사용에 따른 책임은 사용자에게 있어요.
